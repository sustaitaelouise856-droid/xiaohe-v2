> **制定**：2026-10-08 | **批准**：2026-10-08 Elouise 确认开工 | **解释权**：Elouise
> **一句话目标**：做"了解学生的真人语文老师"，目标广州新中考语文 **140 分制**（孩子 2028 年参加中考，适用 2027—2029 新方案：语文从 120 分调整为 140 分，考试 120 分钟不变）——具体分数目标待 Elouise 定（草案建议 110+/140）。

## 第二部分：六大系统模块（具体怎么做）

### 模块一：画像读取验证
- **做什么**：证明系统能读学生画像，并根据画像动态输出不同的下一节课
- **数据结构**：字词（字形/字音/字义分开记录）、文言实词（本义+迁移）、文言虚词、阅读题型（记叙/说明/议论）、作文模块（审题/立意/结构/素材）、背诵篇目，各记 `学过/会了/求助过/错因/跨日证据/最后一次时间`
- **验收**：给定三份不同的模拟画像，输出三个不同的"今日推荐"及原因（一句话）

### 模块二：课程计划主线接入
- **做什么**：课程计划表决定今日课，不是代码写死的顺序
- **规则**：计划表是数据，不是代码；换计划不改程序
- **验收**：改计划表后，首页推荐的课跟着变

### 模块三：课程表（统编版初二上 + 学校同步）
- **做什么**：课程表覆盖统编版初二上册进度 + 领先 1 单元 + 复习节点
- **为什么**：语文教材全国统一用部编版，与英语不同，计划直接对教材单元
- **验收**：任意一天打开，都知道今天该上什么

### 模块四：今日任务优先级总控
- **优先级规则**：
  1. 昨天没做完的题（必须先清）
  2. 到期的旧错复习（D+1/D+4/D+7）
  3. 到期的背诵复测（古诗文跟读默写）
  4. 今日计划新课
  5. 画像薄弱点补底
- **验收**：模拟"有未完成+有到期复习"场景，输出顺序符合优先级

### 模块五：答题批改闭环
- **做什么**：每次答题后更新：作答状态 → 错因分类 → 画像 mastery
- **错因 10 分类**：字形错误 / 字音错误 / 字义错误 / 文言实词不会迁移 / 虚词用法不清 / 翻译漏字颠倒 / 阅读定位失败 / 答题不完整不规范 / 作文审题偏 / 作文结构散
- **验收**：答错一题，画像里该知识点的"错因"字段有记录

### 模块六：抗遗忘复习
- **做什么**：D+1、第 4 天、第 7 天自动推送旧错题（换新题面，不重复原题）；背诵篇目跟读默写同节奏
- **规则**：连续两次换题答对 → 移出复习队列；背诵连续两次默写全对 → 移出
- **验收**：模拟三天学习，第二天首页出现第一天的错字/错实词

## 第三部分：教学链路（每节课内部，七步）

```
情境 → 可理解例子 → 对比 → 一句话规则 → 带帮助练习 → 换材料独立验证 → 跨日复测
```

- 必要讲解必须在第一道相关练习**之前**
- 练习阶段是教练，验证阶段只考试
- 帮助后答对 = "有帮助完成" ≠ 独立掌握
- 三级 HELP：L1 指方向，L2 给不同例子/高亮原文，L3 给答案+解释
- 连续错 3 次 → "先看答案，继续往下"，不卡死

## 第三部分之二：剧情教学（草案，待 Elouise 确认）

**主线（草案）**：小禾文史馆——孩子是文史馆小馆长：
- 整理古籍 → 学文言文
- 审读者来稿 → 学阅读理解
- 练字描红 → 学字词
- 写馆刊征文 → 学作文

四个模块全挂在这一个世界里，孩子不跳戏。

**剧情教学硬要求**：
- 每个知识点必须有稳定的记忆线索：人物 + 地点 + 道具 + 事件，贯穿始终不换
- 剧情只占少量篇幅，学习内容始终是主体（剧情是壳，知识是核）
- 每课开头必须"承上启下"：2 句话回顾上节课的点 + 引出今天的新点
- 复习题优先用剧情回忆式提问，而不是干巴巴的重问

## 第三部分之三：爆笑风格（硬要求）

- 直接采用"爆笑系列"讲法：**打比方、讲段子、不干讲**，让孩子愿意打开
- 参考：夸克「爆笑初中9科全套」→ 看动画学初中语文（4项）
  - 链接：https://pan.quark.cn/s/f91b36133554
  - **注意**：参考它的讲法和选题，不复制内容；夸克链接需手动下载查看，无法自动抓取
- 禁：干巴巴讲定义、整段背诵式讲解
- 要：每个知识点配 1 个生活比方或小段子

## 第三部分之四：语文的特殊性（与英语不同）

| 模块 | 要解决的核心 | 教学要点 |
|------|-------------|---------|
| 字词 | 字形/字音/字义三维，形近字辨析 | 三维分开练，错字进抗遗忘队列 |
| 文言文 | 实词（本义+迁移）、虚词、翻译、背诵 | 实词靠"本义→引申"链条，翻译直译优先，背诵用中文 TTS 跟读 |
| 现代文阅读 | 记叙/说明/议论文答题套路 | 先教套路（读题→定位→原文组织），再出题 |
| 作文 | 整篇：审题、立意、结构、素材 | 从仿写到独立成篇，素材库持续积累 |
| 古诗文默写 | 背+写，错别字 | 跟读+默写，D+1/D+4/D+7 复测 |
| 名著阅读 | 广州中考考查范围 | P2 阶段再做 |

## 第四部分：中考目标分解（广州语文 140 分制，2027—2029 新方案）

孩子 2028 年参加中考，适用新方案：语文 **140 分**、考试 120 分钟，附加题（名著阅读）8 分计入总分但全卷不超过 140 分。三大板块占比与现行方案基本持平，按占比推算：

| 板块 | 分值（约） | 内容 | 现状 |
|------|-----------|------|------|
| 积累与运用 | ~28 | 字词、古诗文默写、语用、综合性学习 | 无 |
| 阅读与鉴赏 | ~54 | 文言文阅读（课内+迁移）+ 现代文阅读 | 无 |
| 表达与交流 | ~58–60 | 写作（600字以上，记叙为主） | 无 |
| 附加题（名著阅读） | 8 | 计入总分 | 无 |

注：写作分值有说法从 50 增至 60，细则待市教育局正式文件核对；"约"为按现行占比推算。现行 120 分制参考（2023 广州卷实测）：积累与运用 24 / 阅读与鉴赏 46 / 写作 50。

**策略**：先把"能稳定拿分的"做扎实（默写、字词、文言实词），再攻阅读套路和作文。

## 第五部分：诊断系统（语文版，待做）

- **新人检测**：字词（听写/辨析）+ 文言（小段翻译）+ 阅读（短文答题）+ 作文（命题小练笔），判断初始水平
- **诊断原则**：不显示对错，只说"收到"；答错不扣分，跳过不罚
- **诊断后**：根据结果推荐起始课程，不是固定从第一课开始

## 第六部分：硬红线（违反任一条不许上线）

1. 教学在系统里，不在聊天里发答案
2. HELP 禁空话（"再想想""选正确答案"类）
3. 反馈只针对孩子实际填写的内容
4. 选项不泄题、不靠中文替代应测能力
5. 孩子可见文字无内部编号、无"很遗憾""太棒了"
6. 阅读材料同屏可见
7. 音频诚实标注：未验证的一律 UNVERIFIED
8. 不修改、不删除孩子数据
9. 上线需本次明确批准
10. 不得编造学习数据、掌握度、分数
11. 课程材料自编原创，不复制课本或试卷原文（沿用英语红线）；古诗文原文属公有领域、为教学必需可引用原文，但讲解/题目/现代文阅读材料必须自编
12. 爆笑风格不能喧宾夺主：段子是引子，知识是主体

## 第七部分：成功标准

**每周只看一个数：孩子实际学习了多少分钟。**

**每月看一个数：学校考试分数有没有提高。**

辅助：独立掌握知识点数、HELP 依赖率、复习通过率、背诵默写通过率。
不考核：题量、在线时长。
