## 三、教学法（从英语验证有效的）

1. **七步教学链路**：情境 → 可理解例子 → 对比 → 一句话规则 → 带帮助练习 → 换材料独立验证 → 跨日复测
2. **三级 HELP**：L1 指方向 → L2 给提示 → L3 给答案+讲解，永不卡死
3. **剧情教学**：数学也可以有剧情——"侦探解方程""工程师建桥"等情境
4. **爆笑风格**：参考"爆笑初中9科全套"——打比方、讲段子，不干讲公式
5. **错因反馈**：每道错题针对性反馈，禁空话
6. **CLIL**：数学+科学/生活应用（一举两得）

---

## 四、数学的特殊性（跟英语语文不一样的地方）

| 模块 | 语言学科做法 | 数学要解决 |
|------|-------------|-----------|
| 公式定理 | 背单词 | 理解推导，不死记；一句话口诀 |
| 例题讲解 | 读课文 | 分步拆解，每步讲"为什么这样做" |
| 练习题 | 选择填空 | 计算题要判分（数字/表达式比对） |
| 几何 | 无 | 图形显示，辅助线思路 |
| 错因 | 8分类 | 计算错/概念错/思路错/看错题 |
| 口诀 | 无 | 公式口诀化（如"勾三股四弦五"） |

**判分特殊**：数学答案可能是数字、表达式，要支持多种等价形式（如 1/2 = 0.5）。

## 五、建议的第一批内容

1. 先定数学总纲（仿照英语 MASTER.md）
2. 初二上册数学核心章节，做 5-10 节示范课
   - 候选：因式分解、分式、勾股定理、一次函数
3. 先做 1 节完整示范课验证流程（含公式显示+判分）
4. 中文 TTS 讲题音频流程验证
