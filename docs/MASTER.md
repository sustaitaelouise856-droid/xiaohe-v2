> **一句话目标**：做"了解学生的真人英语老师"，目标广州新中考 100+/140。

## 第一部分：什么叫真正做好（12 条验收标准）

只有这 12 条形成闭环，才算像真人老师。不是"能出题"，不是"能批改 A/B/C"。

| # | 标准 | 当前状态 |
|---|------|----------|
| 1 | 像真人老师一样**先判断学生当前水平** | ❌ 只有一次新人检测，无持续评估 |
| 2 | 知道学生**今天该学什么**，不是固定 Day1 或随机题 | ❌ 固定顺序播放 |
| 3 | 知道学生**上次有没有未完成题** | ⚠️ 知道进度，不知具体哪题没做完 |
| 4 | 知道**哪些旧错今天该复习** | ❌ 无复习调度 |
| 5 | **本节课只攻一个最小知识点** | ⚠️ 一课多个点；新课按此标准，老课不动 |
| 6 | **先教方法，再出题** | ✅ 已实现 |
| 7 | 答对后**总结英语思维**，不只是说"答对了" | ❌ 只有简短讲解 |
| 8 | 答错后**指出错因、重讲、换题回炉** | ⚠️ 有错因反馈，无重讲+换题 |
| 9 | 从选择题**逐步升级**到填空、改错、真实写句、阅读定位 | ⚠️ 有选择/填空，无改错题型 |
| 10 | 把**当天表现汇总给家长**，不是空模板 | ⚠️ 有三行报告，不够细 |
| 11 | 按**期末倒计时推进**，不临考还讲旧课 | ❌ 无 |
| 12 | **不暴露后台字段**（JSON、rowNum、数据库名等）给学生 | ✅ 检查单在卡 |

## 第二部分：八大系统模块（具体怎么做）

### 模块一：画像读取验证
- **做什么**：证明系统能读 `student_mastery_map`，并根据画像动态输出不同的下一节课
- **数据结构**：每个知识点记录 `学过/会了/求助过/错因/跨日证据/最后一次时间`
- **验收**：给定三份不同的模拟画像，输出三个不同的"今日推荐"及原因（一句话）

### 模块二：课程计划主线接入
- **做什么**：`course_plan_map` 决定今日课，不是代码写死的顺序
- **规则**：计划表是数据，不是代码；换计划不改程序
- **验收**：改计划表后，首页推荐的课跟着变

### 模块三：30天/8周课程表补齐
- **做什么**：批量生成 30 天课程计划，覆盖学校 Unit 进度 + 领先 1 单元 + 复习节点
- **不靠代码写死**：计划存在数据库/配置文件里
- **验收**：任意一天打开，都知道今天该上什么

### 模块四：今日任务优先级总控
- **做什么**：每天按优先级排序任务：未完成题 > 旧错复习 > 今日新课 > 画像补底
- **优先级规则**：
  1. 昨天没做完的题（必须先清）
  2. 到期的旧错复习（D+1/D+4/D+7）
  3. 今日计划新课
  4. 画像薄弱点补底
- **验收**：模拟"有未完成+有到期复习"场景，输出顺序符合优先级

### 模块五：答题批改闭环
- **做什么**：每次答题后更新：作答状态 → 错因分类 → 画像 mastery
- **错因 8 分类**：单词不认识 / 句子没看懂 / 语法不会 / 找不到依据 / 会中文写不出英文 / 拼写 / 粗心 / 没思路
- **验收**：答错一题，画像里该知识点的"错因"字段有记录

### 模块六：抗遗忘复习
- **做什么**：D+1、第 4 天、第 7 天自动推送旧错题（换新题面，不重复原题）
- **规则**：连续两次换题答对 → 移出复习队列
- **验收**：模拟三天学习，第二天首页出现第一天的错题

### 模块七：听写/阅读/写句/口语（新中考能力）
- **做什么**：补齐四类题型
  - 听写：听句子写单词/短语
  - 阅读：中考难度长阅读 + 限时
  - 写句：从仿写到独立写句
  - 口语：跟读复述（文本降级，不强制录音）
- **验收**：每类至少 10 题上线

### 模块八：发布前总验收
- **做什么**：手机端完整跑通一节课：登录 → 上课 → 答题 → HELP → 复习 → 家长报告
- **检查项**：不暴露后台字段、不卡死、音频正常、HELP 有效
- **验收**：真机截图 + 检查单全过

## 第三部分：教学链路（每节课内部，七步）

```
情境 → 可理解例子 → 对比 → 一句话规则 → 带帮助练习 → 换材料独立验证 → 跨日复测
```

- 必要讲解必须在第一道相关练习**之前**
- 练习阶段是教练，验证阶段只考试
- 帮助后答对 = "有帮助完成" ≠ 独立掌握
- 三级 HELP：L1 指方向，L2 给不同例子/高亮原文，L3 给答案+解释
- 连续错 3 次 → "先看答案，继续往下"，不卡死

## 第三部分之二：剧情教学（不能漏的核心设计）

剧情不是装饰，是教学方法本身，有三个作用：

1. **增加学习兴趣**：广播站、电台、侦探等情境让孩子愿意打开
2. **形成记忆宫殿**：知识点挂在人物、地点、事件上，记得牢
3. **帮助回忆提取**：忘记时老师能提醒"还记得那次在车站看第二张通知吗？"，从场景把知识捞回来

**剧情教学硬要求**：
- 每个知识点必须有稳定的记忆线索：人物 + 地点 + 道具 + 事件，贯穿始终不换
- 剧情只占少量篇幅，学习内容始终是主体（剧情是壳，知识是核）
- 每课开头必须"承上启下"：2 句话回顾上节课的点 + 引出今天的新点
- 剧情必须连续：孩子从头到尾在同一个世界里，不跳戏
- 复习题优先用剧情回忆式提问（"还记得……吗"），而不是干巴巴的重问
- HELP 里可以用剧情钩子帮孩子定位（"想想站长是怎么教你的"）

**当前剧情线**：小禾广播站（u2）→ 电脑店（u3）→ 发明（u4）→ 教育交流（u5）→ 古代故事（u6）
**待补**：u7 起的新剧情线；老课的开场"承上启下"2 句话

## 第四部分：硬红线（违反任一条不许上线）

1. 教学在系统里，不在聊天里发答案
2. HELP 禁空话（"再想想""选正确答案"类）
3. 反馈只针对孩子实际填写的内容
4. 选项不泄题、不靠中文替代应测英文能力
5. 孩子可见文字无内部编号、无"很遗憾""太棒了"
6. 阅读材料同屏可见
7. 音频诚实标注：未验证的一律 UNVERIFIED
8. 不修改、不删除孩子数据
9. 上线需本次明确批准

## 第五部分：成功标准

**每周只看一个数：孩子实际学习了多少分钟。**

辅助：独立掌握知识点数、HELP 依赖率、复习通过率。
不考核：题量、在线时长。
