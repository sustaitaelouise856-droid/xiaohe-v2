# 小禾英语总纲 v2：真人老师式 AI 带练系统

> **目的**：任何人、任何时间打开这份文档，都能知道我们要做什么、具体怎么做。
> **制定**：2026-10-08 | **v2 更新**：补周测、家长汇报、学校同步、CLIL 跨学科剧情 | **批准**：待 Elouise 确认 | **解释权**：Elouise
> **一句话目标**：做"了解学生的真人英语老师"，目标广州新中考 100+/140。
> **最高原则**：跟学校同步，学校考试提分是硬证据。学了没用=白学，打击孩子信心。

---

## 第一部分：什么叫真正做好（14 条验收标准）

只有这 14 条形成闭环，才算像真人老师。不是"能出题"，不是"能批改 A/B/C"。

| # | 标准 | 当前状态 |
|---|------|----------|
| 1 | 像真人老师一样**先判断学生当前水平** | ❌ 只有一次新人检测，无持续评估 |
| 2 | 知道学生**今天该学什么**，不是固定 Day1 或随机题 | ❌ 固定顺序播放 |
| 3 | 知道学生**上次有没有未完成题** | ⚠️ 知道进度，不知具体哪题没做完 |
| 4 | 知道**哪些旧错今天该复习** | ❌ 无复习调度 |
| 5 | **本节课只攻一个最小知识点** | ⚠️ 一课多个点；新课按此标准，老课不动 |
| 6 | **先教方法，再出题** | ✅ 已实现 |
| 7 | 答对后**总结英语思维**，不只是说"答对了" | ❌ 只有简短讲解 |
| 8 | 答错后**指出错因、重讲、换题回炉** | ⚠️ 有错因反馈，无重讲+换题 |
| 9 | 从选择题**逐步升级**到填空、改错、真实写句、阅读定位 | ⚠️ 有选择/填空，无改错题型 |
| 10 | 把**当天表现汇总给家长**，不是空模板 | ⚠️ 有三行报告，不够细 |
| 11 | 按**期末倒计时推进**，不临考还讲旧课 | ❌ 无 |
| 12 | **不暴露后台字段**（JSON、rowNum、数据库名等）给学生 | ✅ 检查单在卡 |
| 13 | **跟学校同步**：知道学校教到哪，考前有针对性复习 | ❌ 无同步机制（v2 新增） |
| 14 | **每周有测验**：检验本周所学，给家长可看的结果 | ❌ 无周测（v2 新增） |

## 第二部分：九大系统模块（具体怎么做）

### 模块一：画像读取验证
- **做什么**：证明系统能读 `student_mastery_map`，并根据画像动态输出不同的下一节课
- **数据结构**：每个知识点记录 `学过/会了/求助过/错因/跨日证据/最后一次时间`
- **验收**：给定三份不同的模拟画像，输出三个不同的"今日推荐"及原因（一句话）

### 模块二：课程计划主线接入
- **做什么**：`course_plan_map` 决定今日课，不是代码写死的顺序
- **规则**：计划表是数据，不是代码；换计划不改程序
- **验收**：改计划表后，首页推荐的课跟着变

### 模块三：30天/8周课程表补齐
- **做什么**：批量生成 30 天课程计划，覆盖学校 Unit 进度 + 领先 1 单元 + 复习节点
- **不靠代码写死**：计划存在数据库/配置文件里
- **验收**：任意一天打开，都知道今天该上什么

### 模块四：今日任务优先级总控
- **做什么**：每天按优先级排序任务：未完成题 > 旧错复习 > 今日新课 > 画像补底
- **优先级规则**：
  1. 昨天没做完的题（必须先清）
  2. 到期的旧错复习（D+1/D+4/D+7）
  3. 今日计划新课
  4. 画像薄弱点补底
- **验收**：模拟"有未完成+有到期复习"场景，输出顺序符合优先级

### 模块五：答题批改闭环
- **做什么**：每次答题后更新：作答状态 → 错因分类 → 画像 mastery
- **错因 8 分类**：单词不认识 / 句子没看懂 / 语法不会 / 找不到依据 / 会中文写不出英文 / 拼写 / 粗心 / 没思路
- **验收**：答错一题，画像里该知识点的"错因"字段有记录

### 模块六：抗遗忘复习
- **做什么**：D+1、第 4 天、第 7 天自动推送旧错题（换新题面，不重复原题）
- **规则**：连续两次换题答对 → 移出复习队列
- **验收**：模拟三天学习，第二天首页出现第一天的错题

### 模块七：听写/阅读/写句/口语（新中考能力）
- **做什么**：补齐四类题型
  - 听写：听句子写单词/短语
  - 阅读：中考难度长阅读 + 限时
  - 写句：从仿写到独立写句
  - 口语：跟读复述（文本降级，不强制录音）
- **验收**：每类至少 10 题上线

### 模块八：学校同步机制（v2 新增，最高优先级）
- **为什么**：跟学校脱节=学校考试不提分=孩子觉得"学这个没用"=信心崩盘
- **做什么**：
  1. **学校进度输入**：家长每周输入一次"学校这周教到哪"（如 Unit 3 第 2 课）
  2. **自动对齐**：系统把本周课程往学校进度靠，学校教什么我们就强化什么
  3. **考前冲刺**：学校考试前 3 天自动切换到复习模式，只练考试范围
  4. **成绩录入**：每次学校考试后家长录入分数，系统对比"系统内掌握度 vs 学校分数"
  5. **脱节预警**：如果系统内"会了"但学校考砸了，说明教学脱节，自动调整策略
- **验收**：模拟"学校考 Unit 3，系统在教 Unit 5"，系统能识别脱节并调整

### 模块九：发布前总验收
- **做什么**：手机端完整跑通一节课：登录 → 上课 → 答题 → HELP → 复习 → 家长报告
- **检查项**：不暴露后台字段、不卡死、音频正常、HELP 有效
- **验收**：真机截图 + 检查单全过

## 第三部分：教学链路（每节课内部，七步）

```
情境 → 可理解例子 → 对比 → 一句话规则 → 带帮助练习 → 换材料独立验证 → 跨日复测
```

- 必要讲解必须在第一道相关练习**之前**
- 练习阶段是教练，验证阶段只考试
- 帮助后答对 = "有帮助完成" ≠ 独立掌握
- 三级 HELP：L1 指方向，L2 给不同例子/高亮原文，L3 给答案+解释
- 连续错 3 次 → "先看答案，继续往下"，不卡死

## 第三部分之二：剧情教学（不能漏的核心设计）

剧情不是装饰，是教学方法本身，有三个作用：

1. **增加学习兴趣**：广播站、电台、侦探等情境让孩子愿意打开
2. **形成记忆宫殿**：知识点挂在人物、地点、事件上，记得牢
3. **帮助回忆提取**：忘记时老师能提醒"还记得那次在车站看第二张通知吗？"，从场景把知识捞回来

**剧情教学硬要求**：
- 每个知识点必须有稳定的记忆线索：人物 + 地点 + 道具 + 事件，贯穿始终不换
- 剧情只占少量篇幅，学习内容始终是主体（剧情是壳，知识是核）
- 每课开头必须"承上启下"：2 句话回顾上节课的点 + 引出今天的新点
- 剧情必须连续：孩子从头到尾在同一个世界里，不跳戏
- 复习题优先用剧情回忆式提问（"还记得……吗"），而不是干巴巴的重问
- HELP 里可以用剧情钩子帮孩子定位（"想想站长是怎么教你的"）

**当前剧情线**：小禾广播站（u2）→ 电脑店（u3）→ 发明（u4）→ 教育交流（u5）→ 古代故事（u6）
**已完成**：27 课全部加了"承上启下"开场（2026-10-08）

### 第三部分之三：CLIL 跨学科剧情（v2 新增）

**理念**：用英语学科学、历史、科技，语言和学科知识双收。国际上叫 CLIL，有实证效果。

**2026 热点题材库**：
- 🚀 **嫦娥七号登月**（2026.8 发射，月球南极找水冰）：练将来时+地点表达，学生物理地理
- 🤖 **AI 科学家**（2026 AI 独立做科研）："采访 AI"练问答句型，了解人工智能
- 🔬 **深海探测器失联**（悬疑线）：当调查员读线索，练阅读定位，学生物
- 🛸 **神秘信号解码**（《挽救计划》式）：练逻辑推理，学化学
- 📜 **张衡地动仪**：被动语态（was invented by），历史课直接用
- 🧭 **郑和下西洋**：方位介词，地理历史双补

**落地规则**：
- 不推翻现有 27 课，在 review 课和 u7+ 新课中使用
- 每节课标注"本课还学了：XX 学科 XX 知识"
- 科学概念只用初二能懂的，英语词汇控制在课标内
- 难度：内容新但语言不超纲

## 第四部分：周测系统（v2 新增）

- **频率**：每周一次，固定时间（如周日晚上）
- **内容**：本周所学知识点 + 中考题型（完形/阅读/写作小题）
- **形式**：限时 30 分钟，模拟考试氛围
- **判分**：自动判分，错因归类
- **输出**：
  1. 本周掌握度报告（每个知识点：掌握/待加强/未掌握）
  2. 与上周对比（进步/退步）
  3. 下周学习建议（自动调整课程计划）
- **家长可见**：周测成绩单，含错题和改进建议
- **验收**：连续 4 周周测，数据能画出进步曲线

## 第五部分：家长汇报系统（v2 新增，详细版）

### 每日三行（自动推送）
```
今天学了 X 分钟，完成 [课程名] 第 X 步
新掌握：[知识点]；还需加强：[知识点]
明天计划：[课程名]
```

### 每周报告（周日）
- 本周总学习分钟数 + 趋势图
- 周测成绩 + 与上周对比
- 掌握知识点清单（新增/巩固/待加强）
- HELP 使用率（依赖度变化）
- 下周计划

### 学校考试后专项报告
- 学校分数录入
- 系统内掌握度 vs 学校分数对比
- 脱节分析（如有）
- 针对性补强计划

### 预警机制
- 连续 3 天未学习 → 提醒家长
- HELP 依赖率突然升高 → 提醒难度可能过高
- 周测退步 → 提醒并给出原因分析

## 第六部分：硬红线（违反任一条不许上线）

1. 教学在系统里，不在聊天里发答案
2. HELP 禁空话（"再想想""选正确答案"类）
3. 反馈只针对孩子实际填写的内容
4. 选项不泄题、不靠中文替代应测英文能力
5. 孩子可见文字无内部编号、无"很遗憾""太棒了"
6. 阅读材料同屏可见
7. 音频诚实标注：未验证的一律 UNVERIFIED
8. 不修改、不删除孩子数据
9. 上线需本次明确批准
10. **v2 新增**：不得编造学习数据、掌握度、分数

## 第七部分：成功标准

**每周只看一个数：孩子实际学习了多少分钟。**

**每月看一个数：学校考试分数有没有提高。**

辅助：独立掌握知识点数、HELP 依赖率、复习通过率、周测趋势。
不考核：题量、在线时长。

## 第八部分：中考 100+ 目标分解（140 分制）

| 题型 | 分值 | 现状 | 缺口 |
|------|------|------|------|
| 听力听说 | ~30 | 104 个真音频 | 缺整套听说模拟 |
| 阅读理解 | ~40 | 课文阅读有 | 缺中考难度长阅读+限时 |
| 完形填空 | ~15 | 无 | 整块缺失 |
| 语法词汇 | ~20 | 课内语法有 | 缺 2000 词体系 |
| 写作 | ~25 | 写句子有 | 缺整篇作文训练 |

**策略**：71% 得分率即可达标，不追求满分。优先补提分最快的短板。

## 第九部分：诊断系统

- **新人检测**：A/B 卷，三部分（单词语音语法/阅读听力/写句朗读），判断初始水平
- **诊断原则**：不显示对错，只说"收到"；答错不扣分，跳过不罚
- **诊断后**：根据结果推荐起始课程，不是固定从第一课开始
