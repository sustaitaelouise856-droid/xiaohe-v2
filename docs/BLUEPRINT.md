# 小禾英语设计蓝图 v1

> 一句话：做"了解学生的真人英语老师"，不是刷题器。
> 制定：2026-10-08 | 批准：待 Elouise 确认 | 解释权：Elouise

---

## 一、我们是什么（是什么）

小禾英语是一位**知道学生是谁、知道她哪里不会、知道学校正在学什么**的英语老师。
老师主动通过连续有趣的剧情教她：不会就换方法，会了就继续，永远有合适的下一节课。

## 二、我们不是什么（非目标，同样重要）

- 不是刷题器：不以题量、分钟数为教学目标
- 不是答案机：不直接给答案代替思考（Khanmigo 原则："没人靠被给答案学会任何东西"）
- 不是承诺机：不承诺自动补练、长期掌握、中考提分
- 不是聊天机器人：教学发生在课程系统里，不在聊天里讲题

## 三、教学链路（怎么做，七步缺一不可）

```
情境 → 可理解例子 → 对比 → 一句话规则 → 带帮助练习 → 换材料独立验证 → 跨日复测
```

- 必要讲解必须出现在第一道相关练习**之前**
- 练习阶段是教练（可提示），验证阶段只考试（不提示）
- 帮助后答对 = "有帮助完成"，≠ 独立掌握
- 跳过 ≠ 正确；看过答案 ≠ 学会

## 四、四个子系统（借鉴 Duolingo Birdbrain / MATHia 架构）

| 子系统 | 作用 | 当前状态 |
|--------|------|----------|
| 学生画像 | 记录每个知识点的学过/会了/求助/错因/跨日证据 | 部分实现，需加强 |
| 知识地图 | 知识点之间依赖关系，先学什么后学什么 | 缺失，待建 |
| 教学决策器 | 根据画像决定下一步：教新/补弱/复测/推进剧情 | 缺失，待建 |
| 互动课堂 | 剧情+讲解+练习的连续体验 | 已实现，需打磨 |

 pedagogical 约束写进架构，不只写进提示词。

## 五、硬红线（违反任何一条不许上线）

1. 教学必须发生在系统里，不在聊天里发答案
2. HELP 禁空话（L1 指方向，L2 给不同例子/高亮原文，L3 给答案+解释）
3. 练习连续错 3 次必须出现"先看答案，继续往下"
4. 反馈只针对孩子实际填写的内容
5. 选项不泄题、不靠中文替代应测的英文能力
6. 孩子可见文字无内部编号、无"很遗憾""太棒了"类空话
7. 阅读材料必须同屏可见
8. 音频标注诚实：未人耳验证的一律 UNVERIFIED，不写 PASS
9. 不修改、不删除孩子作答数据
10. 正式上线必须获得本次明确批准，不沿用旧批准

## 六、内容标准

- 选择题：12 题时 A/B/C/D 各 3 次，最长连续相同 ≤2 次，无固定规律
- 音频：Warm Pebble 音色，英文 120–130 WPM，-20 LUFS，配慢速再听
- 剧情只占少量篇幅，学习内容始终是主体
- 练习必须新编，不复制学校试卷整题

## 七、成功标准（每周只看一个数）

**孩子实际学习了多少分钟。**

辅助指标：独立掌握的知识点数、HELP 依赖率、跨日复测通过率。
不考核：题量、在线时长、AI 回复数。
