## 第二部分：六大系统模块（具体怎么做）

### 模块一：画像读取验证
- **做什么**：证明系统能读学生画像，并根据画像动态输出不同的下一节课
- **数据结构**：计算（有理数/整式/分式运算分开记录）、几何（图形识别/证明思路）、函数（图像/解析式）、错因（计算错/概念错/思路错/看错题），各记 `学过/会了/求助过/错因/跨日证据/最后一次时间`
- **验收**：给定三份不同的模拟画像，输出三个不同的"今日推荐"及原因（一句话）

### 模块二：课程计划主线接入
- **做什么**：课程计划表决定今日课，不是代码写死的顺序
- **规则**：计划表是数据，不是代码；换计划不改程序
- **验收**：改计划表后，首页推荐的课跟着变

### 模块三：课程表（初二上册 + 学校同步）
- **做什么**：课程表覆盖初二上册数学进度 + 领先 1 单元 + 复习节点
- **为什么**：最高原则要求跟学校同步，学校教什么我们就强化什么
- **教材版本**：与学校核对后定（广州初中多用人教版，待确认）
- **验收**：任意一天打开，都知道今天该上什么

### 模块四：今日任务优先级总控
- **优先级规则**：
  1. 昨天没做完的题（必须先清）
  2. 到期的旧错复习（D+1/D+4/D+7，换新题面）
  3. 今日计划新课
  4. 画像薄弱点补底（错因高频项优先）
- **验收**：模拟"有未完成+有到期复习"场景，输出顺序符合优先级

### 模块五：答题批改闭环（含等价判分）
- **做什么**：每次答题后更新：作答状态 → 错因分类 → 画像 mastery
- **错因 4 分类**：
  1. **计算错**：会方法、算错了（如符号、约分漏项）→ 回炉：同类计算专项
  2. **概念错**：公式/定义记错用错（如把 (a+b)² 展开成 a²+b²）→ 回炉：重讲概念+口诀
  3. **思路错**：不知道从哪下手、辅助线想不到 → 回炉：分步拆解带练
  4. **看错题**：抄错数、漏条件 → 回炉：审题训练，不加难度
- **等价形式判分**：`1/2 = 0.5`、`x²-1 = (x+1)(x-1)` 展开/因式两方向都算对；数字答案允许等值不同写法；**不得因书写形式不同把正确答案判错**
- **验收**：答错一题，画像里该知识点的"错因"字段有记录；同一答案的 3 种等价写法判分一致

### 模块六：抗遗忘复习
- **做什么**：D+1、第 4 天、第 7 天自动推送旧错题（换新题面，不重复原题）
- **规则**：连续两次换题答对 → 移出复习队列
- **错因定向**：计算错多 → 复习时多给计算题；概念错多 → 复习时先重讲再练
- **验收**：模拟三天学习，第二天首页出现第一天的错题（新题面）

## 第三部分：教学链路（每节课内部，七步）

```
情境 → 可理解例子 → 对比 → 一句话规则 → 带帮助练习 → 换材料独立验证 → 跨日复测
```

数学版落地：

- **情境**：剧情钩子引入（见第三部分之二）
- **可理解例子**：一道孩子看得懂的例题，分步拆解，**每一步讲"为什么这样做"**
- **对比**：对的思路 vs 孩子最可能犯的错（如完全平方公式漏掉 2ab），一眼看出区别
- **一句话规则**：公式口诀化（如"首平方、尾平方、首尾二倍在中央"）
- **带帮助练习**：分步带练，HELP 三级可用
- **换材料独立验证**：换数字、换题面，方法不变
- **跨日复测**：D+1 换题再考

- 必要讲解必须在第一道相关练习**之前**
- 练习阶段是教练，验证阶段只考试
- 帮助后答对 = "有帮助完成" ≠ 独立掌握
- 三级 HELP：L1 指方向（"先想第一步干什么"），L2 给提示（高亮关键条件/举个小例子），L3 给答案+分步讲解
- 连续错 3 次 → "先看答案，继续往下"，不卡死

## 第三部分之二：剧情教学（草案，待 Elouise 确认）

两个候选主线，请 Elouise 拍板（二选一或她定新的）：

**候选 A：侦探解方程**（**草案默认值，Elouise 可随时改**）——孩子是小侦探，每个知识点是一起"案件"：
- 因式分解 → "把赃物拆开看"（把多项式拆成因子的乘积）
- 勾股定理 → "现场测量"（直角三角形量边长破案）
- 一次函数 → "追踪嫌疑人行踪"（图像就是行动轨迹）
- 错题 → "悬案重查"（复习=旧案新线索）

**候选 B：工程师建桥**——孩子是小工程师，每个知识点是建桥的一道工序：
- 因式分解 → "拆零件"（结构件拆解）
- 勾股定理 → "量桥墩"（直角测量定桩位）
- 一次函数 → "画坡度"（桥面坡度就是直线）
- 错题 → "返工单"（哪里塌了补哪里）

**剧情教学硬要求**：
- 每个知识点必须有稳定的记忆线索：人物 + 地点 + 道具 + 事件，贯穿始终不换
- 剧情只占少量篇幅，学习内容始终是主体（剧情是壳，知识是核）
- 每课开头必须"承上启下"：2 句话回顾上节课的点 + 引出今天的新点
- 复习题优先用剧情回忆式提问（"还记得上次那个案子是怎么破的吗"），而不是干巴巴的重问

## 第三部分之四：数学的特殊性（与英语语文不同）

| 模块 | 要解决的核心 | 教学要点 |
|------|-------------|---------|
| 公式显示 | 数学公式要好看、手机上能看清 | 方案二选一：KaTeX 渲染 或 公式图片；**先在示范课验证再批量做**，验证项：手机端清晰度、加载速度、离线可用 |
| 几何图形 | 几何题没图等于没题 | SVG 矢量图展示；辅助线分步出现（先虚线思路、再实线定稿）；图形可放大 |
| 计算题判分 | 答案是数字/表达式，不是 A/B/C | 等价形式判分（见模块五）；分步给分（思路对、计算错≠全错） |
| 错因分类 | 不是"不会"两个字能概括的 | 计算错/概念错/思路错/看错题四分类，回炉策略各不同 |
| 公式口诀 | 公式太多，死记记不住 | 每个核心公式配一句话口诀；口诀只帮助记忆，不替代理解 |
| 理解推导 | 死记公式一换题就垮 | 每个公式讲"怎么来的"（如完全平方公式用面积图推）；能复述推导思路才算掌握 |

## 第四部分：中考目标分解（广州数学 140 分制，2027—2029 新方案）

孩子 2028 年参加中考，适用新方案：数学 **140 分**。三大领域占比与现行 120 分制基本持平，按占比推算：

| 领域 | 分值（约） | 内容 | 现状 |
|------|-----------|------|------|
| 数与代数 | ~72 | 数与式、方程与不等式、函数 | 无 |
| 图形与几何 | ~50 | 三角形、四边形、圆、图形变换 | 无 |
| 统计与概率 | ~18 | 数据收集整理、概率初步 | 无 |

注：现行 120 分制参考（广州卷实测约）：数与代数 ~62 / 图形与几何 ~43 / 统计与概率 ~15；"约"为按现行占比推算。**考试时长、题型结构等细则待市教育局正式文件核对，不编造。**

**策略**：79% 得分率即可达 110+。优先补提分最快的短板：
1. **计算基本功**（数与代数）：分值最大，且是所有题的地基——计算错丢的分最冤
2. **几何说理**（图形与几何）：从"会算"升级到"会写过程"，步骤分好拿
3. **函数图像**（数与代数）：一次函数是初二核心，图像+解析式双向翻译

## 第五部分：诊断系统（数学版，待做）

- **新人检测**：计算（有理数运算/整式化简）+ 几何（基本图形识别/简单说理）+ 函数（坐标系/描点），分项摸底
- **诊断原则**：不显示对错，只说"收到"；答错不扣分，跳过不罚
- **诊断后**：根据结果推荐起始课程，不是固定从第一课开始；计算弱的先补计算再上新课

## 第六部分：硬红线（违反任一条不许上线）

1. 教学在系统里，不在聊天里发答案
2. HELP 禁空话（"再想想""选正确答案"类）
3. 反馈只针对孩子实际填写的内容
4. 选项不泄题、不靠中文替代应测能力
5. 孩子可见文字无内部编号、无"很遗憾""太棒了"
6. 阅读材料同屏可见
7. 音频诚实标注：未验证的一律 UNVERIFIED
8. 不修改、不删除孩子数据
9. 上线需本次明确批准
10. 不得编造学习数据、掌握度、分数
11. 课程材料自编原创，不复制课本或试卷原文（沿用英语红线）
12. 爆笑风格不能喧宾夺主：段子是引子，知识是主体
13. **公式显示方案先验证再批量**：KaTeX/图片二选一，示范课验证通过前不批量生产
14. **等价判分**：同一正确答案的不同等价写法必须判分一致，不得因形式不同判错
15. **几何题必须有图**：不出无图的几何题；图形看不清=题目不合格

## 第七部分：成功标准

**每周只看一个数：孩子实际学习了多少分钟。**

**每月看一个数：学校考试分数有没有提高。**

辅助：独立掌握知识点数、HELP 依赖率、复习通过率、计算正确率趋势。
不考核：题量、在线时长。
